# SAFE GUARD

**AI 기반 피싱 및 사기 예방 서비스**

의심스러운 순간, SAFE GUARD가 함께 확인합니다.

SAFE GUARD는 문자, 카카오톡 대화 및 대화 캡처 이미지를 AI로 분석하여 사기 위험 신호를 발견하고, 사용자가 피해 발생 전 적절하게 대응할 수 있도록 돕는 웹 서비스입니다.

🔗 **서비스 바로가기:** [https://haehae.vercel.app/](https://haehae.vercel.app/)

---

## 1. 프로젝트 배경 및 문제점

보이스피싱, 스미싱, 중고 거래 사기 등 디지털 금융 사기 수법이 다양해지면서 일반 사용자가 사기 여부를 스스로 판단하기 어려워지고 있습니다.

기존 사기 예방 및 조회 서비스에는 다음과 같은 한계가 존재합니다.

- 사기에 대한 사전지식이 부족하면 위험 신호를 인지하기 어려움.
- 사용자가 먼저 사기를 의심해야 관련 정보를 검색하거나 조회할 수 있음.
- 신고 이력만으로는 실제 대화에서 어떤 부분이 위험한지 판단하기 어려움.
- 사기가 의심되더라도 어떤 행동을 취해야 하는지 알기 어려움.
- 계속해서 변화하는 사기 수법과 예방 정보를 파악하기 어려움.

> **기존 서비스는 사용자가 먼저 사기를 의심해야 이용할 수 있지만, 실제로는 사기라는 사실조차 인지하지 못하는 경우가 있습니다.**

SAFE GUARD는 이러한 문제에 주목하여 전문적인 보안 지식이 없어도 일상적인 대화 속 위험 신호를 확인하고, 상황에 맞게 대응할 수 있도록 개발되었습니다.

## 3. 가산점 카드 – 🎮 내가 이 구역의 해결사

**선택 가산점 카드: 🎮 내가 이 구역의 해결사**

SAFE GUARD는 일상 속 디지털 금융 사기 문제를 해결하기 위해 다음과 같은 기능을 구현했습니다.

| 기존 문제점 | SAFE GUARD의 해결 방안 |
| --- | --- |
| 사기에 대한 사전지식 부족 | AI 기반 대화 및 이미지 분석 |
| 사기 위험 신호를 스스로 판단하기 어려움 | 위험도 시각화 및 의심 문장 강조 |
| 단편적인 신고 이력 중심의 정보 제공 | 대화의 맥락을 고려한 위험 요소 및 판단 근거 제공 |
| 사기 의심 상황에서 대응 방법을 알기 어려움 | AI 맞춤형 답장 추천 및 안전 점검 체크리스트 |
| 피해 발생 후 대응 절차에 대한 정보 부족 | 단계별 긴급 대응 가이드 및 신고 기관 안내 |
| 지속적으로 변화하는 사기 수법 | KISA RSS 기반 공식 사기 예방 정보 제공 |

단순한 사기 정보 조회를 넘어 다음과 같은 과정으로 일상 속 디지털 금융 사기 문제를 해결하고자 합니다.

**위험 인지 → 위험 분석 → 안전 대응 → 피해 예방**

## 4. 주요 기능

### ① AI 대화 분석 및 위험도 시각화

- 문자 및 메신저 대화 직접 입력, 캡처 이미지 업로드
- 대화의 전체 맥락을 고려한 AI 위험도 분석
- 높음, 주의, 낮음, 판단 어려움의 4단계 위험도 분류
- 사기 의심 문장 강조 및 구체적인 판단 근거 제공


### ② AI 맞춤형 대응 가이드

- 대화 상황에 맞는 안전한 답장 생성 및 복사
- 상대방 신원, 계좌 명의, 개인정보 요구 여부 등을 확인하는 송금 전 안전 점검 체크리스트
- 분석 결과에 따른 상황별 행동 지침 제공


### ③ 피해 발생 시 긴급 대응 지원

- 추가 송금 중단 및 대화·송금 내역 등 증거 보관 안내
- 피해 발생 시 단계별 대응 절차 제공
- 경찰청 ECRM, 112, 금융감독원 1332 등 관련 신고 및 상담 기관 안내


### ④ 공식 사기 예방 정보

- KISA 보호나라 RSS 기반 공식 보안공지 수집
- Supabase Edge Functions 및 Cron을 활용한 매시간 자동 수집 구조
- 피싱, 스미싱, 보이스피싱, 기관 사칭 등 유형별 정보 제공


### ⑤ 통합 위험 정보 조회

- URL, 계좌번호, 전화번호별 통합 조회 인터페이스
- 입력 정보의 형식 검증 및 조회 결과 예시 제공
- 더치트 외부 서비스 연결

※ 실제 더치트 API는 현재 미연동 상태입니다.


### ⑥ 회원 관리 및 마이페이지

- 회원가입, 로그인 및 비밀번호 재설정
- IndexedDB 기반 사용자별 검사 기록 저장
- 이전 분석 결과 확인, 검색 및 삭제

## 5. 서비스 차별점

### 대화의 맥락을 고려한 위험 분석

전화번호나 계좌번호의 신고 이력에만 의존하지 않고, 대화 속 기관 사칭, 비정상적인 송금 요구, 심리적 압박 등의 위험 신호를 종합적으로 분석합니다.


### 위험도 판단부터 실제 대응까지

위험도를 안내하는 데 그치지 않고, 판단 근거와 상황에 맞는 답장, 안전 점검 체크리스트 및 단계별 대응 방법을 함께 제공합니다.


### 공식 보안정보 기반의 지속적인 정보 제공

정적인 예방 정보에 의존하지 않고 KISA의 공식 보안공지를 RSS 기반으로 수집하여 변화하는 사기 수법과 예방 정보를 확인할 수 있도록 구성했습니다.

## 7. 서비스 구조

### AI 대화 분석

사용자 입력 → React → Supabase Edge Functions → Gemini API → 위험도 분석 및 맞춤형 대응 안내


### 공식 사기 예방 정보

KISA RSS → Supabase Edge Functions → PostgreSQL → 공식 사기 예방 정보 게시판


### 사용자 관리

Supabase Auth를 통한 사용자 인증 및 IndexedDB를 활용한 사용자별 검사 기록 관리

## 9. 유의 사항

SAFE GUARD의 AI 분석 결과는 사기 위험을 판단하기 위한 참고 정보이며, 실제 사기 여부나 거래의 안전성을 보장하지 않습니다.

의심스러운 상황에서는 공식 정보를 추가로 확인하고 관련 기관을 통해 상담받는 것을 권장합니다.
